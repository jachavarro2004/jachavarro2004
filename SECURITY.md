# Security policy

This repository is Jhon Chavarro's GitHub profile: a README and its images,
with no code to run. A security problem in Jhon belongs to jhon-agent, so
please follow
[jhon-agent's security policy](https://github.com/jachavarro2004/jhon-agent/blob/main/SECURITY.md).

Please do not open a public issue, discussion or pull request for a
vulnerability. Open a private report from
[jhon-agent's Security tab](https://github.com/jachavarro2004/jhon-agent/security)
(Report a vulnerability), or, if you cannot use GitHub, write to
jhon87195@outlook.com.
