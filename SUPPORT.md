# Getting help with Jhon

This repository is Jhon Chavarro's GitHub profile. Jhon itself lives in
[jhon-agent](https://github.com/jachavarro2004/jhon-agent), and so does its
help:

- **A question or an idea to talk through:** open a
  [Discussion](https://github.com/jachavarro2004/jhon-agent/discussions).
- **A bug or a proposal:** open an
  [issue](https://github.com/jachavarro2004/jhon-agent/issues/new/choose)
  in jhon-agent; its
  [SUPPORT.md](https://github.com/jachavarro2004/jhon-agent/blob/main/SUPPORT.md)
  describes what to include.
- **A security problem:** never in public; see [SECURITY.md](SECURITY.md).
